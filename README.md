# ApêSync 

> "Sincronizando a convivência, dividindo os custos sem dividir a amizade."

## Sobre o Projeto
O **ApêSync** é um aplicativo móvel voltado para a gestão automatizada de moradias compartilhadas, integrando rateio inteligente de compras via OCR e organização dinâmica de tarefas domésticas.
